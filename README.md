## What is this?

Roblox AI helps you show an AI assistant **what you want to build**, instead of relying on vague descriptions. Use visual examples for HUDs, menus, Roblox game art, animation, VFX, studio workflows, and more.

The collection mixes public Roblox promotional/reference imagery, original mockups, documentation images and other visual inspirations. **Reference does not mean free-to-reuse.** Build an original result and respect the creators' rights.

## Use with Claude or Codex

1. **Pick a goal:** choose the folder that matches your project, such as `ui-styles/`, `vfx/` or `game-refs/sports/`.
2. **Attach actual images:** select 2–5 relevant PNG, JPEG, WebP or GIF files. Don't send a directory name and expect the assistant to see its contents.
3. **Specify the rules:** name the design patterns to take from each reference, plus what must be different.
4. **Request Roblox-ready output:** ask for Luau scripts, Roblox UI objects, hierarchy, sizing, input handling, and test steps.
5. **Review in Studio:** check desktop and mobile layouts, performance and rights before publishing.

### Copyable prompt

```text
I'm building an original Roblox experience in Roblox Studio.
Use the attached references for visual direction, not direct copying.

Goal: [describe the gameplay feature or UI]
Visual priorities: [colors, composition, spacing, typography, effects]
Constraints: [R6/R15, PC/mobile/controller, art style, performance]

Implement the feature in Roblox-compatible Luau and Studio objects.
Explain the Explorer hierarchy, scripts, UI sizing and how to test.
Keep the result responsive and readable on multiple screen sizes.
Do not reuse another game's logos or copyrighted artwork.
```

## Contributing

Contributions should improve **quality and discoverability**, not just increase the number.

- Add real, readable **PNG, JPEG, WebP, or GIF images**, rather than link files or placeholders.
- Choose the correct category; use descriptive filenames that explain the subject.
- Prefer high-resolution, relevant visuals and avoid exact duplicates.
- Include attribution and source/license information where practical.
- Avoid unsafe files, suspicious downloads, tracking material and unrelated content.
- Keep original project code, game assets and proprietary graphics subject to their creators' terms.
